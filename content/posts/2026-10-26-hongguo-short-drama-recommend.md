先给网站，这篇只推荐这一个东西：

> **红果长剧清单**：[https://11os.github.io/hongguo-longdrama-list/](https://11os.github.io/hongguo-longdrama-list/)

在红果里找剧刷，最烦的是首页推荐位：你看得越多，它推得越像。这个网站解决的就是这件事——把红果上累计集数够长的剧全部拉出来，做成一张**能自己搜、自己筛、自己排序**的表。不用登录，纯静态页面，打开就能用。

![桌面端打开红果长剧清单：门槛与频道筛选、搜索框、排序按钮，以及每部剧名字后面的口碑关键词标签](/img/hongguo-list/desktop-top.webp)

*桌面端首屏：第一排是门槛（≥300 / ≥500 / ≥800 集）、频道（男频 / 女频 / 待定）、搜索框和重置；第二排是七个排序键加「展开全部评论」；下面是四张统计卡，再往下每行是剧名、规模、题材、口碑标签和评分收藏点赞评论数。*

## 网站上有什么

### 1. 表头点一下就排序

累计集数、季数、单季最大集数、评分、收藏、点赞、评论数，全都能排。想找「评分最高的长篇」，点「评分」列；想找「量大的」，点「累计集数」列。**不用再一路刷推荐位碰运气。**

排序按钮右边还有个「展开全部评论」：点一下把当前筛选结果里所有剧的评论抽屉一起打开，再点一下（变成「收起全部评论」）全收回去。想快速扫一遍差评关键词时用这个，比一部一部点快得多。

### 2. 三级门槛 + 频道 + 搜索

- **门槛**：≥300 集（963 部）/ ≥500 集（484 部）/ ≥800 集（210 部）
- **频道**：男频 / 女频 / 待定
- **搜索**：剧名、类型、评论关键词都能搜，空格分隔多个词是「同时满足」

搜索是这一版新加的，也是最省事的入口。比如在搜索框里敲「不拖沓」，≥500 集口径下只剩 149 部；再敲成「不拖沓 不后宫」，只剩 33 部——两个词要同时被评论提到。标题会跟着变（`红果长剧清单 · ≥500 集 · 不拖沓`），顶上的统计卡也一起重算。

搜错了点输入框右边的 ✕ 清空；点「重置」把门槛、频道、排序、搜索一起回到初始（≥500 集 / 全部频道 / 累计集数降序）。

![搜索「不拖沓」：≥500 集口径下 149 部，标题和统计卡同步变化](/img/hongguo-list/desktop-search.webp)

*桌面端搜索「不拖沓」：标题变成「≥500 集 · 不拖沓」，统计卡从 484 变成 149（男 103 / 女 46 / 待定 0），标签里的「不拖沓」全部高亮。*

（本文数据对应 2026-10-27 18:11 生成的页面。≥500 集口径下：484 部，男频 302 / 女频 178 / 待定 4，其中多季系列 359 部，最长的一部累计 8644 集。）

### 3. 看评论避坑——这是最有用的一块

每部剧名字后面挂着一串从观众评论里提炼的**关键词标签**，分两档：

| 颜色 | 含义 | 例子 |
|---|---|---|
| 绿色 | 事实性好评 | 不拖沓、杀伐果断、搞事业、不恋爱 |
| 红色 | 肯定式差评 | 后宫、圣母、狗血、拖沓 |

每档默认只露前几个，后面挂一个「+N」，点开看全部，再点「收起标签」收拢——一部剧的标签能有三四十个，全铺开就没法扫了。

想细看就点「评论摘要 N 条」，抽屉里是一条条从评论里截出来的原话，**差评排在前面**——先让你看到缺点，再决定要不要花几十、上百小时。命中词会高亮，片段左边的色条区分差评（浅红）/ 好评（浅绿）/ 褒贬都有（橙）。

![点开「评论摘要」展开的片段列表：差评排在前面，命中词高亮](/img/hongguo-list/desktop-comments.webp)

*点开「评论摘要 18 条」就是这样（图里是《持械入宋》）：红色的「出戏」「憋屈」排在最前面、左边是红条；往下的好评是绿条，命中词全部高亮，底部「收起评论」收回去。*

判断规则很简单：**你想看的剧，看它标签里有没有密集的「舔狗」「绿茶」「憋屈」；有就跳过。** 这比看评分快得多。

### 4. 复制剧名 + 链接定位 + 随便看看

每行有个「复制剧名」按钮，点一下剪贴板里就有剧名（1.4 秒内显示「已复制」），复制完去红果 App 里搜。

想直接把某部剧发给别人，用链接：`https://11os.github.io/hongguo-longdrama-list/?name=持械入宋`。打开就滚到那一行、高亮、并自动展开它的评论——即使它不在当前门槛里，门槛 / 频道 / 搜索也会自动放开（写成 `#剧名` 也行）。

右下角那个「随便看看」是在当前筛选结果里随机挑一部、滚过去闪一下——不知道看什么的时候用。

**网站只负责筛，播放还是在红果。**

## 为什么它比推荐位好用

因为它给的是**全量数据 + 差评优先**，而不是算法想让你点开的东西。

我按网站上 963 部（≥300 集口径）的关键词统计了一下。下面的数字是「**有多少部剧出现该关键词**」：

**好评 TOP 9**

| 关键词 | 部数 |
|---|---|
| 不拖沓 | 174 |
| 杀伐果断 | 120 |
| 可以看 | 117 |
| 不无脑 | 111 |
| 不圣母 | 102 |
| 搞事业 | 95 |
| 无感情线 | 85 |
| 不后宫 | 81 |
| 不狗血 | 75 |

**差评 TOP 10**

| 关键词 | 部数 |
|---|---|
| 舔狗 | 52 |
| 绿茶 | 49 |
| 憋屈 | 47 |
| 圣母 | 46 |
| 洗白 | 31 |
| 无脑 | 28 |
| 出戏 | 25 |
| 工具人 | 23 |
| 后宫 | 17 |
| 烂尾 | 11 |

两张表对着看，结论有点意思：**好评前九名里，四个是「不 X」**——不拖沓、不无脑、不圣母、不狗血。

也就是说，观众现在判断一部短剧，不是看它多爽，而是看它**多不烦**。爽是基本盘，真正让人退出的往往是节奏慢、感情线乱、配角当工具人。

好评档里还有一串感情线指标——无感情线 85 部、不后宫 81 部、不恋爱 35 部、无感情戏 33 部（≥300 集口径）。**观众把「没有感情线」当成优点在夸，而不是当愿望在许**：能专心搞事业的主角，比会谈恋爱的更受欢迎。

（早前站点单独列过一档「期望」标签，用灰色虚线标「盼无感情线」这类愿望；这一版已把它并进好评 / 差评两档，本文的关键词统计也按两档重算过。）

## 数据口径（避免误读）

- **三条门槛是同一份数据的三种切法**：≥300 集 963 部 / ≥500 集 484 部 / ≥800 集 210 部；下文的关键词统计统一按 ≥300 集口径算。
- **标签两档**：好评 / 差评都来自评论原文；「拖沓」「后宫」这类评价词在好评档里只以「不拖沓」「不后宫」的否定形式出现，所以两档不能直接相加。
- **同名不同季已合并**：集数是系列累计，季数是已收录季数。
- **评分取最高一季**：多季作品质量并不一致，看最高分会高估。
- **收藏 / 点赞 / 评论为各季合计**。
- **关键词来自评论抽样**：反映的是愿意在评论区打字的观众，样本不代表全量评论。
- **样本不是全量**：只收录累计集数够长的剧，红果的实际内容远不止这些。
- **数据会变**：短剧更新极快，页面会重新生成，数字随时可能变。
