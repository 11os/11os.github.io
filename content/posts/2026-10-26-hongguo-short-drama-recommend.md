先给网站，这篇只推荐这一个东西：

> **红果长剧清单**：[https://11os.github.io/hongguo-longdrama-list/](https://11os.github.io/hongguo-longdrama-list/)

在红果里找剧刷，最烦的是首页推荐位：你看得越多，它推得越像。这个网站解决的就是这件事——把红果上累计集数够长的剧全部拉出来，做成一张**能自己排序、自己筛选**的表。不用登录，纯静态页面，打开就能用。

## 网站上有什么

### 1. 表头点一下就排序

累计集数、季数、单季最大集数、评分、收藏、点赞、评论数，全都能排。想找「评分最高的长篇」，点「评分」列；想找「量大的」，点「累计集数」列。**不用再一路刷推荐位碰运气。**

### 2. 两级门槛 + 频道筛选

- **门槛**：≥300 集（963 部）/ ≥500 集（484 部）
- **频道**：男频 / 女频 / 待定

（本文数据对应 2026-10-26 12:31 生成的页面。≥500 集口径下：484 部，男频 302 / 女频 178 / 待定 4，其中多季系列 359 部，最长的一部累计 8644 集。）

### 3. 看评论避坑——这是最有用的一块

每部剧名字后面挂着一串从观众评论里提炼的**关键词标签**，分三类：

| 颜色 | 含义 | 例子 |
|---|---|---|
| 绿色 | 事实性好评 | 不拖沓、杀伐果断、搞事业 |
| 红色 | 肯定式差评 | 后宫、圣母、狗血、拖沓 |
| 灰色虚线 | 期望（是愿望，不是事实） | 盼无感情线、盼不后宫 |

点「评论」还能展开具体评论片段，**差评排在前面**——先让你看到缺点，再决定要不要花几十、上百小时。命中词会高亮，片段底色也区分好评（浅绿）/ 差评（浅红）/ 褒贬都有（橙色）/ 期望（蓝灰）。

判断规则很简单：**你想看的剧，看它标签里有没有密集的「舔狗」「绿茶」「憋屈」；有就跳过。** 这比看评分快得多。

### 4. 一键复制剧名

每行有个「复制剧名」按钮，复制完去红果 App 里搜。**网站只负责筛，播放还是在红果。**

## 为什么它比推荐位好用

因为它给的是**全量数据 + 差评优先**，而不是算法想让你点开的东西。

我按网站上 963 部（≥300 集口径）的关键词统计了一下。下面的数字是「**有多少部剧出现该关键词**」：

| 不拖沓 | 174 |
| 杀伐果断 | 120 |
| 可以看 | 117 |
| 不无脑 | 111 |
| 不圣母 | 102 |
| 搞事业 | 95 |

**差评 TOP 10**

| 关键词 | 部数 |
|---|---|
| 舔狗 | 52 |
| 绿茶 | 49 |
| 憋屈 | 47 |
| 圣母 | 46 |
| 洗白 | 31 |
| 无脑 | 28 |
| 出戏 | 25 |
| 工具人 | 23 |
| 后宫 | 17 |

两张表对着看，结论有点意思：**好评前九名里，四个是「不 X」**——不拖沓、不无脑、不圣母、不狗血。

也就是说，观众现在判断一部短剧，不是看它多爽，而是看它**多不烦**。爽是基本盘，真正让人退出的往往是节奏慢、感情线乱、配角当工具人。

期望类关键词（盼无感情线 52 部、盼不后宫 38 部、盼不恋爱 21 部）说的是同一件事：**观众会主动许愿，说明他们很清楚自己想看什么**，只是作品不总是给。能专心搞事业的主角，比会谈恋爱的主角更受欢迎。

## 数据口径（避免误读）

- **同名不同季已合并**：集数是系列累计，季数是已收录季数。
- **评分取最高一季**：多季作品质量并不一致，看最高分会高估。
- **收藏 / 点赞 / 评论为各季合计**。
- **关键词来自评论抽样**：反映的是愿意在评论区打字的观众，样本不代表全量评论。
- **样本不是全量**：只收录累计集数够长的剧，红果的实际内容远不止这些。
- **数据会变**：短剧更新极快，页面会重新生成，数字随时可能变。
