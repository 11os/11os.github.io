## 这是什么

一个用来存放思考与实践的个人站点。

基于 [Hugo](https://gohugo.io) 构建，主题是 [Stack](https://github.com/CaiJimmy/hugo-theme-stack)，托管在 GitHub Pages。全部内容以 Markdown 写在仓库里，改完推一下就自动发布。

## 内容方向

- **推荐** —— 看过、用过、真心觉得好的东西，写清楚好在哪、坑在哪。
- **实践** —— 做过的事、踩过的坑、总结出的方法。

## 写给谁

如果某篇文章对你有点用，那它就值了。

## 关于写作

教育的本质是引导，而非灌输。所以这里尽量少说"你应该怎样"，多说"我是怎么想的、发生了什么"。

> 接下来所有内容将尝试用引导的方式，以我为例引发思考。

## 技术栈

| 部分 | 选择 | 理由 |
|---|---|---|
| 静态站点生成 | Hugo 0.168.0 (extended) | 单二进制，构建毫秒级，十年后还能跑 |
| 主题 | Stack v4 | 多语言 + 深色模式开箱，评论系统 14 种 provider |
| 托管 | GitHub Pages | 免服务器、免备案、推代码即发布 |
| CI | GitHub Actions | 官方 Pages 发布链路，构建零人工干预 |

内容全部纯静态，零客户端框架运行时 —— 首屏只有一个 HTML 和一个 CSS 文件。
